## **PART 8: REMOTE WORKFORCE SECURITY (10 Slides)**

**Slide 1: The New Normal: Remote Work Security**
* Hybrid & remote setups increase flexibility but also attack surface
* Employees face new threats: insecure Wi-Fi, shared devices, lost laptops
* Remote security = responsibility of every employee
* Recent breaches due to insecure remote access

**Slide 2: VPN & Network Security**
* Always use company-approved VPN for internal systems
* Avoid public Wi-Fi for sensitive work
* If necessary, use personal hotspot or VPN
* **Home network security:**
  - Strong Wi-Fi password
  - Regular firmware updates
  - Guest networks for visitors
  - Disable WPS (Wi-Fi Protected Setup)

**Slide 3: Device Security for Remote Work**
* Encrypt laptops (BitLocker/FileVault) and mobile devices
* Keep OS, apps, and antivirus updated
* Enable screen lock and remote wipe capabilities
* Avoid sharing devices with family or roommates
* Use company-approved security software
* Regular backup of important data

**Slide 4: Cloud & File Sharing Security**
* Use only approved cloud tools (Google Workspace, OneDrive, Nextcloud)
* Avoid personal drives or messaging apps for company data
* Enable MFA for all cloud accounts
* Encrypt sensitive files before sharing externally
* Use company-approved collaboration platforms
* Regular review of shared file permissions

**Slide 5: Communication Security**
* Be aware of phishing via email, Slack, Teams, or Zoom
* Avoid clicking links or downloading attachments from unknown sources
* Verify unexpected requests through second channel (phone call)
* Use encrypted communication tools for sensitive discussions
* Be cautious of meeting links from unknown senders

**Slide 6: Social Engineering & Remote Attacks**
* Common attacks for remote workers: vishing, smishing, fake support calls
* Attackers exploit isolation and urgency
* Always follow company verification protocols
* Be suspicious of unsolicited tech support offers
* Verify any request for remote access to your device

**Slide 7: Workstation & Physical Security**
* Lock your laptop when stepping away (Win+L / Ctrl+Cmd+Q)
* Use privacy screens if working in shared spaces
* Keep sensitive documents out of sight
* Secure your home office when not in use
* Don't discuss sensitive information in public areas
* Be aware of your surroundings during video calls

**Slide 8: Secure Home Office Setup**
* **Physical Security:** Lock doors/windows, secure devices
* **Network Security:** Updated router, strong passwords, firewall enabled
* **Device Management:** Company devices only for work, separate user accounts
* **Data Protection:** Encrypted storage, secure disposal of documents
* **Access Control:** Restrict family access to work devices

**Slide 9: Remote Security Policies**
* Follow company policies for remote login, password management, device use
* Regular attendance at security trainings and simulations
* Immediate reporting of lost/stolen devices
* Compliance with data handling and storage policies
* Use of approved software and tools only
* Regular security self-assessments

**Slide 10: Remote Work Security Checklist**
- [ ] Use VPN for all company resource access
- [ ] Enable full-disk encryption on all devices
- [ ] Keep all software and systems updated
- [ ] Use MFA for all accounts and services
- [ ] Secure home Wi-Fi with strong password
- [ ] Lock devices when not in use
- [ ] Use privacy screens in public spaces
- [ ] Report security incidents immediately
- [ ] Follow data handling policies strictly
- [ ] Participate in security awareness training
