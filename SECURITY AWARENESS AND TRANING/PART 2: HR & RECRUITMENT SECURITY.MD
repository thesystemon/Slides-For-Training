## **PART 2: HR & RECRUITMENT SECURITY (10 Slides)**

**Slide 1: HR: The Human Gateway to Cybersecurity**
* Handle most sensitive data: CVs, IDs, bank details, salary slips
* Real case: HR clicked "resume.zip" → malware spread company-wide
* 82% of HR professionals receive phishing emails (Proofpoint, 2024)

**Slide 2: Common Threats Targeting HR**
* Phishing Resumes (.zip, .docm attachments)
* Fake Job Portals stealing HR credentials
* Social Engineering Calls for employee verification
* Data Exfiltration by insiders
* Third-party Vendor Risks from background agencies

**Slide 3: Data Privacy & PII Handling**
| Data Type | Example | Handling Rule |
|-----------|---------|---------------|
| Basic PII | Name, phone, email | Store in secure HRMS |
| Sensitive PII | PAN, Aadhaar, medical info | Encrypt and restrict access |
| Financial Info | Salary, bank details | Secure transfer only |
| Background Checks | Legal/educational data | Verified partners only |

**Slide 4: Secure HR Data Handling Lifecycle**
1. **Collection:** Gather only necessary data, get consent
2. **Storage:** Use secure HRMS tools, encrypt backups
3. **Access & Sharing:** Limit to authorized HR, use approved tools
4. **Disposal:** Delete per retention policy, shred documents

**Slide 5: Social Engineering Defense for HR**
* Common Scenarios: Fake candidates, vendor requests, auditor calls
* **Golden Rule:** "Verify first — share never"
* Always verify caller identity via official contacts
* Never share employee data over phone/SMS
* Report suspicious communications immediately

**Slide 6: Secure Recruitment Process**
| Stage | Risk | Security Practice |
|-------|------|-------------------|
| Job Posting | Fake job ads | Post on verified domains only |
| Screening | Malware resumes | Open in sandbox/preview mode |
| Interview | Calendar scams | Confirm invite links & domains |
| Offer Letter | Fake offers | Digital signature + letterhead |
| Onboarding | Data exposure | Use encrypted portals |

**Slide 7: Insider Threats in HR**
* **Malicious Insider:** HR employee selling data
* **Negligent Insider:** Leaving files open/shared
* **Accidental Insider:** Sending wrong attachment
* **Prevention:** Access logs, Clean Desk policy, double-checking

**Slide 8: Legal & Compliance for HR**
* **India DPDP Act:** Collect only with consent, retain minimum data
* **GDPR:** Right to be forgotten, lawful processing
* **ISO 27001/SOC 2:** Confidentiality & audit trails
* **Company Policy:** Follow HRIS security SOP

**Slide 9: HR Security Checklist**
- [ ] Collect data only through official forms
- [ ] Store resumes in secure HRMS only
- [ ] Don't open resumes from unknown emails
- [ ] Encrypt files with personal data
- [ ] Delete old candidate data as per policy
- [ ] Verify all third-party HR vendors
- [ ] Lock systems when leaving desk
- [ ] Don't share data on WhatsApp or Gmail

**Slide 10: HR Security Key Takeaways**
* HR = first and last line of defense for employee data
* Verify every request before sharing personal/salary info
* Store candidate data securely, delete responsibly
* Don't click/download attachments from unknown applicants
* Report suspicious calls, emails, or vendors
* Protecting candidate trust = protecting company reputation
