## **PART 4: DETECTION & ANALYSIS TECHNIQUES (20 Slides)**

**Slide 1: Advanced Detection Mindset**
* Move from basic recognition to proactive analysis
* Understand attacker techniques to better defend
* Develop critical thinking for digital communications

**Slide 2: The 5-Second Pause Technique**
* **Stop:** Don't react immediately to any request
* **Look:** Carefully examine the message
* **Think:** Does this make sense in context?
* **Verify:** Use alternate channels if unsure
* **Act:** Proceed only after verification

**Slide 3: Sender Analysis Deep Dive**
* **Email Address Examination:**
  - Check for character substitution (0 vs O, 1 vs l)
  - Look for extra words or characters
  - Verify domain spelling carefully
  - Check for subdomain tricks

**Slide 4: Language and Tone Analysis**
* **Grammar Patterns:** Unusual errors for supposed sender
* **Formality Level:** Mismatch with relationship or context
* **Urgency Indicators:** Excessive exclamation points, capitalization
* **Personalization:** Generic vs specific references
* **Cultural Cues:** Language mismatches for supposed origin

**Slide 5: Technical Indicator Analysis**
* **Header Inspection:** SPF, DKIM, DMARC alignment
* **Link Structure:** Hover to see true destinations
* **Attachment Types:** File extensions and naming patterns
* **Image Quality:** Low-resolution or stolen logos
* **Formatting:** Inconsistent styling or branding

**Slide 6: Contextual Analysis Framework**
* **Timing:** Is this a normal time for this communication?
* **Relationship:** Is this request appropriate for our relationship?
* **Content:** Does this information make sense in our context?
* **Channel:** Is this the right channel for this type of request?
* **Procedure:** Does this follow our normal workflows?

**Slide 7: Psychological Pattern Recognition**
* **Emotional Triggers:** Identify manipulation attempts
* **Authority Cues:** Fake urgency or importance
* **Social Proof:** False claims about others' actions
* **Scarcity Tactics:** Artificial limitations or deadlines
* **Reciprocity Plays:** Fake previous favors or assistance

**Slide 8: Real-Time Analysis Exercises**
* **Exercise 1:** Analyze suspicious email as a group
* **Exercise 2:** Compare legitimate vs phishing messages
* **Exercise 3:** Identify red flags in sample communications
* **Exercise 4:** Practice verification procedures
* **Exercise 5:** Group discussion of detection strategies

**Slide 9: Mobile-Specific Detection**
* **Link Previews:** Long-press to see destination URLs
* **App Impersonation:** Fake login screens for mobile apps
* **Notification Abuse:** Malicious push notifications
* **SMS Shortcodes:** Fake official short code messages
* **QR Code Safety:** URL preview before navigation

**Slide 10: Advanced Link Analysis**
* **URL Deconstruction:** Break down link components
* **Domain Age:** Check when domain was registered
* **Certificate Examination:** SSL certificate details
* **Redirect Tracing:** Multiple hops to final destination
* **Pattern Recognition:** Common malicious URL structures

**Slide 11: Attachment Analysis Protocol**
* **File Type Verification:** Actual vs claimed file types
* **Hash Checking:** Verify file integrity when possible
* **Sandbox Testing:** Safe environment for suspicious files
* **Metadata Examination:** File creation details
* **Size Analysis:** Unusually large or small files

**Slide 12: Behavioral Analysis Techniques**
* **Communication Patterns:** Unusual timing or frequency
* **Request Patterns:** Abnormal requests for relationship
* **Language Patterns:** Changes in writing style
* **Response Patterns:** Pressure for immediate action
* **Evasion Patterns:** Avoiding normal verification

**Slide 13: Cultural and Regional Awareness**
* **Language Nuances:** Local expressions and phrasing
* **Time Zone Awareness:** Appropriate communication times
* **Holiday Considerations:** Regional holiday patterns
* **Business Practices:** Normal procedures for region
* **Cultural Norms:** Expected communication styles

**Slide 14: Industry-Specific Detection**
* **Healthcare:** Patient data requests and compliance
* **Finance:** Payment procedures and verification
* **Legal:** Client confidentiality and document handling
* **Education:** Student data protection
* **All:** Credential and data protection

**Slide 15: Advanced Verification Methods**
* **Out-of-Band Verification:** Different communication channel
* **Pre-established Codes:** Shared verification phrases
* **Multi-person Verification:** Multiple approvers for sensitive actions
* **Documentation Review:** Verify against known documents
* **Procedure Compliance:** Follow established workflows

**Slide 16: Digital Forensics Basics**
* **Header Analysis:** Email routing information
* **IP Tracing:** Geographic and ownership data
* **Timestamp Analysis:** Send and receive timing
* **Attachment Analysis:** File characteristics and hashes
* **Link Analysis:** Destination and redirect patterns

**Slide 17: Pattern Recognition Development**
* **Common Themes:** Identify recurring attack patterns
* **Seasonal Trends:** Holiday and event-based attacks
* **Industry Targeting:** Specific attacks for your sector
* **Geographic Patterns:** Regional attack characteristics
* **Temporal Patterns:** Time-based attack frequency

**Slide 18: Critical Thinking Exercises**
* **Scenario 1:** Urgent financial request analysis
* **Scenario 2:** Credential request evaluation
* **Scenario 3:** Unexpected attachment assessment
* **Scenario 4:** Social media contact vetting
* **Scenario 5:** Phone call verification practice

**Slide 19: Continuous Learning Approach**
* **Stay Updated:** Follow security news and trends
* **Share Knowledge:** Discuss attacks with colleagues
* **Learn from Incidents:** Analyze successful and stopped attacks
* **Practice Regularly:** Participate in security exercises
* **Adapt Techniques:** Evolve detection methods

**Slide 20: Analysis Mastery Commitment**
* "I will pause and analyze before acting"
* "I will verify through multiple methods"
* "I will continuously improve my detection skills"
* "I will share knowledge with my team"
