## **PART 3: SAFE WEB BROWSING & MALICIOUS SITES (20 Slides)**

**Slide 1: Introduction / Hook**
* "You open a website, click a link… and suddenly your screen freezes"
* Modern attacks start with unsafe browsing
* One wrong click = Malware, data theft, system lock

**Slide 2: Why Safe Browsing Matters**
* 70% malware infections from malicious sites
* **Attack methods:** SEO poisoning, malvertising
* Trusted sites can be compromised
* Safe browsing = Proactive human defense

**Slide 3: Anatomy of Malicious Websites**
* No HTTPS / broken padlock
* Strange domain names (micorsoft.com)
* Overloaded pop-ups and redirections
* Fake antivirus/update prompts
* Automatic file downloads

**Slide 4: Understanding HTTPS & Padlocks**
* HTTPS = Encrypted communication
* ⚠️ Padlock ≠ Safe site
* Always check domain name + certificate
* Use official bookmarks for sensitive sites

**Slide 5: Fake Software & Drive-by Downloads**
* "Download Now!" pop-ups hide malware
* Drive-by attacks install silently
* **Safe habits:**
  - Official sources only
  - Disable auto-downloads
  - Keep browsers updated

**Slide 6: Browser Extensions & Hijacks**
* Extensions can spy and steal data
* Install from trusted sources only
* Review permissions regularly
* Avoid "Allow Notifications" on random sites

**Slide 7: Corporate Web Filtering**
* **Tools:** Web filters, proxies, DNS protection
* **Benefits:** Block known malicious sites
* **Employee responsibility:**
  - Don't bypass filters
  - Report blocked site issues
  - Use VPN on public Wi-Fi

**Slide 8: Public Wi-Fi Security**
* Public Wi-Fi = Untrusted network
* **Risks:** Traffic interception, fake hotspots
* **Protection:**
  - Always use VPN
  - Disable file sharing
  - Avoid sensitive logins

**Slide 9: Browser Sandboxing & Profiles**
* Modern browsers sandbox tabs
* **Best practices:**
  - Keep browsers updated
  - Separate work/personal profiles
  - Avoid random plugins

**Slide 10: Reporting Suspicious Websites**
* Close tab immediately
* Report to IT/SOC with:
  - URL
  - Screenshot
  - Timestamp
* Use browser "Report unsafe site" feature

**Slide 11: Browser Security Settings**
* ✅ Auto-update ON
* ✅ Disable pop-ups globally
* ✅ Clear cookies/cache regularly
* ✅ Turn off password saving
* ✅ Enable Safe Browsing mode

**Slide 12: Hands-On Activity 1 - Spot Fake Sites**
* Show 3 website screenshots
* Identify real vs fake by checking:
  - Domain spelling
  - SSL certificates
  - Content quality

**Slide 13: Hands-On Activity 2 - Browser Settings**
* Participants open browser settings
* Enable security options:
  - Safe browsing
  - Pop-up blocking
  - Notification controls

**Slide 14: Hands-On Activity 3 - Extension Audit**
* Review installed extensions
* Remove unknown/unnecessary ones
* Check permission levels
* Discuss security implications

**Slide 15: Real Case Study**
* **Incident:** "Zoom Update.exe" from fake site
* **Impact:** Malware → Ransomware entry
* **Lesson:** Verify URLs, use official sources

**Slide 16: Safe Download Practices**
* Verify website authenticity
* Check file hashes when available
* Scan downloads before opening
* Use company-approved sources
* Report suspicious download prompts

**Slide 17: Mobile Browser Security**
* Same risks as desktop browsers
* Use secure mobile browsers
* Avoid downloading unknown apps
* Keep mobile OS updated
* Use VPN on mobile networks

**Slide 18: Social Engineering via Websites**
* Fake login pages
* Tech support scams
* "You've won" pop-ups
* Fake survey sites
* Always verify before entering information

**Slide 19: Browser Security Checklist**
- [ ] Keep browser and plugins updated
- [ ] Use HTTPS everywhere
- [ ] Enable pop-up blocking
- [ ] Regular extension audits
- [ ] Use bookmarks for important sites
- [ ] Clear browsing data regularly
- [ ] Report suspicious sites immediately

**Slide 20: Safe Browsing Commitment**
* "Verify before you click"
* "Update before you browse"
* "Report before it spreads"
* "Think before you download"
