## **PART 1: PHISHING & EMAIL THREATS (20 Slides)**

**Slide 1: Title / Hook**
* **PHISHING & EMAIL THREATS**
* "How attackers trick people — and exactly what you should do"
* Turning employees into an active line of defense

**Slide 2: What is Phishing?**
* **Definition:** Social engineering attack using fake messages
* **Methods:** Email, SMS, voice calls
* **Goals:** Steal sensitive information, install malware, gain access
* **Why it works:** Exploits trust, urgency, fear, curiosity, authority

**Slide 3: Real-World Consequences**
* Credential theft → Account takeover
* Malware/Ransomware infection
* Data breaches → Customer/company data exposed
* Financial fraud & Business Email Compromise (BEC)
* Reputational damage & regulatory fines

**Slide 4: Common Signs of Phishing (Visual Checklist)**
* Urgent/threatening language
* Mismatched sender addresses
* Spelling/grammar errors
* Unexpected attachments (.ZIP, .EXE, macro files)
* Shortened or suspicious links
* Generic greetings
* Requests for credentials/OTPs

**Slide 5: Types of Phishing Attacks**
* **Email Phishing:** Mass emails pretending to be trusted entities
* **Spear Phishing:** Targeted attacks with personal information
* **Business Email Compromise (BEC):** Executive impersonation
* **Smishing:** SMS-based phishing
* **Vishing:** Voice call scams
* **Quishing:** QR code phishing

**Slide 6: Anatomy of a Phishing Email**
* **From:** Display name vs actual sender mismatch
* **Subject:** Urgent call-to-action
* **Pre-header:** Suspicious teaser text
* **Body:** Short paragraph demanding action
* **Links/Buttons:** Disguised malicious URLs
* **Attachments:** Dangerous file types
* **Footer:** Fake company signatures

**Slide 7: How to Inspect Links Safely**
* Hover to preview destination
* Check for domain typos (micr0soft.com)
* Look for HTTPS and legitimate domains
* Use link checkers when unsure
* Mobile: Long-press to preview URLs

**Slide 8: Attachment Safety Guidelines**
* **Never open:** .EXE, .SCR, .BAT, .MSI, macro-enabled files
* **Be cautious with:** .ZIP files from unknown senders
* **Always:** Confirm expected attachments via alternate channels
* **Company policy:** All attachments scanned by security tools

**Slide 9: Social Engineering Psychology**
* **Urgency:** "Act now or lose access"
* **Authority:** "CEO needs this immediately"
* **Scarcity/Curiosity:** "Limited time offer"
* **Reciprocity/Trust:** Using internal references
* **Fear:** "Your account will be suspended"

**Slide 10: Reporting Procedure - Step by Step**
1. Don't click any links in the message
2. Use "Report Phishing" button in email client
3. Forward to SOC: phish@company.com
4. Include subject: "Suspected Phish - [Brief note]"
5. For credential entry: Immediate IT notification

**Slide 11: Immediate Response - If You Clicked**
* Disconnect from network (if instructed)
* Inform IT/SOC immediately via phone
* Change affected passwords from clean device
* Revoke active sessions
* Reset MFA if compromised
* Monitor for suspicious activity

**Slide 12: Business Email Compromise (BEC)**
* **Red Flags:**
  - Last-minute invoice changes
  - New payment instructions
  - Pressure to keep requests secret
* **Controls:**
  - Verify via known phone numbers
  - Dual-approval workflows
  - Vendor invoice whitelisting
  - Positive pay for bank transfers

**Slide 13: Practical Detection Tools**
* Outlook "Report Message" add-in
* One-click reporting rules
* Department security champions
* Quick-reference PDF guides
* Security awareness dashboard

**Slide 14: Hands-On Activity 1 - Email Analysis**
* Live demo of safe email examples
* Show link hovering techniques
* Demonstrate header inspection
* Practice reporting procedures

**Slide 15: Hands-On Activity 2 - Group Exercise**
* Show 6 email screenshots (mixed real/fake)
* Teams identify phishing attempts
* Discuss red flags found
* Share detection strategies

**Slide 16: Phishing Simulation Program**
* **Goal:** Measure and improve detection skills
* **Method:** Controlled GoPhish campaigns
* **Ethics:** No real credentials captured
* **Templates:** Password expiry, HR documents, delivery notifications
* **Landing:** Educational messages with feedback

**Slide 17: Measurement & KPIs**
* Phish-prone percentage (click rate)
* Report rate percentage
* Credential submission rate
* Trend analysis over time
* Departmental performance breakdown

**Slide 18: Trainer Preparation Checklist**
* Client permission and scope agreement
* Sanitized example emails prepared
* Reporting tools configured
* Simulation templates ready
* Demo machine isolated
* Quizzes and activities prepared

**Slide 19: Employee Cheat Sheet**
* **Top 5 Signs:**
  1. Urgent language
  2. Mismatched senders
  3. Suspicious attachments
  4. Strange links
  5. Credential requests
* **Quick Actions:** Don't click → Report → Forward → Call IT if compromised

**Slide 20: Phishing Defense Commitment**
* "Think before you click"
* "Verify before you trust"
* "Report before it spreads"
* Continuous vigilance protects everyone
