## **PART 2: PASSWORDS, MFA & CREDENTIAL SAFETY (20 Slides)**

**Slide 1: Title / Hook**
* **PASSWORDS, MFA & CREDENTIAL SAFETY**
* "Make compromised passwords useless with better habits and MFA"

**Slide 2: Why Passwords Still Matter**
* Primary gatekeeper for most accounts
* Weak/reused passwords = Easy breaches
* Attackers use: Brute force, credential stuffing, phishing
* Strong passwords + MFA = Dramatic risk reduction

**Slide 3: Password Myths vs Reality**
* **Myth:** Complex short passwords are best
* **Reality:** Length beats complexity
* **Myth:** Reuse is OK with frequent changes
* **Reality:** Reuse multiplies risk across breaches
* **Myth:** Symbols always make passwords safe
* **Reality:** Predictable substitutions are weak

**Slide 4: Creating Strong Passphrases**
* **Length:** ≥12 characters recommended
* **Format:** 3-4 random words (BlueCoffee!Train7)
* **Avoid:** Common phrases, sequences, personal info
* **Uniqueness:** Different for every account
* **Tool:** Use password managers for generation

**Slide 5: Password Manager Benefits**
* Store unlimited unique passwords
* Generate strong random passwords
* Auto-fill login forms securely
* **Options:** Bitwarden, KeePass, 1Password, LastPass
* **Security:** Strong master passphrase + MFA

**Slide 6: Multi-Factor Authentication (MFA)**
* **What:** Extra verification beyond password
* **Factors:**
  - SMS OTP (basic protection)
  - Authenticator apps (recommended)
  - Hardware tokens (most secure)
  - Push notifications (convenient)
* **Always enable:** Email, cloud apps, banking, VPN

**Slide 7: MFA Setup Demonstration**
* Enable TOTP on sample account
* Show QR code scanning process
* Demonstrate backup methods
* Explain device revocation process
* Practice with test accounts

**Slide 8: Credential Theft Methods**
* **Credential Stuffing:** Reuse across sites
* **Brute Force:** Automated login attempts
* **Phishing:** Fake login pages
* **Keyloggers:** Malware capturing keystrokes
* **Password Spraying:** Common passwords across users

**Slide 9: Checking for Credential Leaks**
* Use trusted services (HaveIBeenPwned)
* Scan email addresses for breaches
* Immediate action if found leaked
* Change passwords and enable MFA
* Monitor for suspicious activity

**Slide 10: Corporate Password Policies**
* **Minimum length:** 12 characters
* **No reuse:** Track via manager or policy
* **Password history:** Prevent recycling
* **Account lockout:** After repeated failures
* **MFA enforcement:** All privileged accounts

**Slide 11: Compromise Response Steps**
1. Change password from trusted device
2. Revoke all active sessions
3. Reset MFA if compromised
4. Check other accounts for reuse
5. Open IT support ticket
6. Follow incident guidance

**Slide 12: Hands-On Activity 1 - Passphrase Workshop**
* Teams create 3 sample passphrases
* Evaluate strength and memorability
* Share best practices
* Discuss common pitfalls

**Slide 13: Hands-On Activity 2 - Password Manager Demo**
* Create demo password vault
* Show password generation
* Demonstrate auto-fill features
* Practice secure sharing

**Slide 14: Hands-On Activity 3 - MFA Setup**
* Participants set up TOTP
* Practice with test accounts
* Configure backup methods
* Understand recovery processes

**Slide 15: Enforcement vs Persuasion**
* **Enforce:** Critical systems, privileged accounts
* **Persuade:** Training, champions, easy tools
* **Provide:** Password managers, setup guides
* **Reduce:** Friction through good UX

**Slide 16: Measurement & KPIs**
* MFA adoption rate (target >90%)
* Password manager usage
* Password strength scores
* Credential exposure response
* Incident reduction over time

**Slide 17: Trainer Preparation**
* Demo accounts for MFA setup
* Password manager installation
* Passphrase worksheets
* Policy documentation
* Step-by-step handouts

**Slide 18: Employee Cheat Sheet**
* **Top 5 Tips:**
  1. Use long passphrases
  2. Unique for every account
  3. Use password manager
  4. Enable MFA everywhere
  5. Never share credentials

**Slide 19: Credential Security Culture**
* "Length over complexity"
* "Unique for every site"
* "MFA is non-negotiable"
* "Manager makes it manageable"

**Slide 20: Password Security Pledge**
* "I will use strong, unique passwords"
* "I will enable MFA on all accounts"
* "I will use a password manager"
* "I will report suspected compromises"
