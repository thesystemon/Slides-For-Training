## **PART 6: DATA HANDLING & PRIVACY (20 Slides)**

**Slide 1: Data is the New Oil**
* "Every click, form, email contains valuable data"
* "Once leaked, data can't be taken back"
* **Value:** Personal info for identity theft, company data for espionage
* **Requirement:** Legal and ethical obligation

**Slide 2: Data Privacy vs Protection**
* **Data Privacy:** How data is collected, used, stored, shared
* **Data Protection:** Technical safeguards enforcing privacy
* **Example:**
  - Privacy: Deciding access rights
  - Protection: Encryption and access controls

**Slide 3: Data Classification Types**
* **Public Data:** Company blog, advertisements
* **Internal Data:** Staff contacts, policies
* **Confidential Data:** Financials, project documents
* **PII:** Names, IDs, email addresses
* **Sensitive Personal:** Health, biometric, salary data

**Slide 4: Data Classification & Labeling**
* **Purpose:** Clear handling instructions
* **Labels:**
  - "Confidential - Internal Use Only"
  - "Restricted - HR Department Only"
  - "Public - Safe to Share"
* **Implementation:** Consistent across organization

**Slide 5: Data Handling Lifecycle**
1. **Collection:** Minimum necessary, with consent
2. **Storage:** Approved systems with encryption
3. **Access & Use:** Need-to-know basis
4. **Sharing & Transmission:** Secure methods only
5. **Retention & Disposal:** Policy compliance

**Slide 6: Unsafe Data Practices**
* Personal email for company data
* Cloud storage with personal accounts
* Messaging apps for sensitive information
* Unsecured printed documents
* Personal USB drives for work data
* Shared system logouts neglected

**Slide 7: Secure Email & File Sharing**
* Double-check recipients before sending
* Use encryption for sensitive files
* **Approved Tools:**
  - Microsoft 365 SharePoint
  - Google Workspace Drive
  - Nextcloud
* **Avoid:** WeTransfer, personal Dropbox, Telegram

**Slide 8: Data Privacy Laws Overview**
* **GDPR (EU):** Consent, right to be forgotten
* **ISO 27001:** Risk-based security framework
* **India DPDP Act:** User consent, data minimization
* **HIPAA (US):** Health data protection
* **PCI-DSS:** Payment card security

**Slide 9: Physical Data Security**
* Locked file cabinets
* Shredders for confidential documents
* Immediate print collection
* Secure access card management
* No photos of screens/documents

**Slide 10: Data Breach Response**
1. Don't delete or hide the incident
2. Report immediately to security officer
3. Provide full details of what happened
4. Contain through access revocation
5. Follow company breach procedures

**Slide 11: Data Minimization Principle**
* Collect only what's necessary
* Retain only as long as needed
* Regular data cleanup schedules
* Purpose limitation in collection
* Employee awareness of requirements

**Slide 12: Cloud Data Security**
* Strong access controls
* Encryption in transit and at rest
* Regular access reviews
* Backup and recovery testing
* Compliance with data residency

**Slide 13: Hands-On Activity 1 - Data Classification**
* Classify sample data items:
  - Employee ID card
  - Customer invoice
  - CCTV footage
  - Marketing brochure
* Discuss handling requirements

**Slide 14: Hands-On Activity 2 - Secure Sharing**
* Practice encrypted file sharing
* Demonstrate secure email practices
* Show proper disposal methods
* Discuss common mistakes

**Slide 15: Hands-On Activity 3 - Breach Simulation**
* Simulate data leak scenario
* Practice reporting procedures
* Discuss containment steps
* Review lessons learned

**Slide 16: Case Study - Data Breach**
* **Scenario:** HR email with salary sheet to wrong department
* **Impact:** Internal data breach, employee trust damage
* **Lesson:** Always verify recipients, use secure methods

**Slide 17: Data Privacy KPIs**
* Classification compliance rate
* Data breach incident reports
* Training completion percentages
* Policy adherence metrics
* Audit finding resolutions

**Slide 18: Data Handling Checklist**
- [ ] Classify data before handling
- [ ] Use approved storage systems
- [ ] Encrypt sensitive information
- [ ] Verify recipients before sharing
- [ ] Follow retention schedules
- [ ] Secure physical documents
- [ ] Report incidents immediately
- [ ] Regular policy reviews

**Slide 19: Data Protection Responsibilities**
* **Everyone's Job:** All employees handle data
* **Accountability:** Personal responsibility for protection
* **Continuous Learning:** Stay updated on requirements
* **Culture:** Privacy as organizational value
* **Compliance:** Legal and ethical obligation

**Slide 20: Data Protection Pledge**
* "I will classify and handle data properly"
* "I will use secure sharing methods"
* "I will follow retention policies"
* "I will report incidents immediately"
* "I will protect customer and company data"
