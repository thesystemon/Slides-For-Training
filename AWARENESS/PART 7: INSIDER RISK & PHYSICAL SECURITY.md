
## **PART 7: INSIDER RISK & PHYSICAL SECURITY (20 Slides)**

**Slide 1: Understanding Insider Risks**
* "Not every attack comes from outside"
* **Definition:** Employee/contractor misuse of access
* **Types:**
  - Malicious (intentional)
  - Negligent (careless)
  - Compromised (hacked)

**Slide 2: Common Insider Risk Scenarios**
* **Credential Sharing:** "Use my login quickly"
* **Data Download:** Personal device transfers
* **Revenge Actions:** Disgruntled employee damage
* **Code Exposure:** Public repository uploads
* **Phished Access:** Compromised account misuse

**Slide 3: Why Insider Incidents Happen**
* Weak access controls
* Poor offboarding procedures
* Lack of security awareness
* Unsecured physical environments
* Unmanaged personal devices

**Slide 4: Physical Security Basics**
* "Cybersecurity starts at the door"
* **Golden Rules:**
  - Always wear ID badges
  - Prevent tailgating
  - Lock screens when away
  - Secure devices always
  - Protect access credentials

**Slide 5: Clean Desk & Clear Screen Policy**
* "What's on your desk can be stolen faster than what's on your desktop"
* **Requirements:**
  - Lock confidential documents
  - Shred unneeded papers
  - No password notes
  - Screen lock when away
  - Secure removable media

**Slide 6: Data & Device Protection**
* Company-approved devices only
* Unknown USB drive prohibition
* Regular OS and antivirus updates
* Full-disk encryption enabled
* Lost device immediate reporting

**Slide 7: Visitors & Contractors Policy**
* No unknown person access
* Visitor escort requirements
* No photography in secure areas
* Meeting room security
* Vendor identity verification

**Slide 8: Recognizing Suspicious Behavior**
* Unusual large data transfers
* Unauthorized USB usage
* After-hours system access
* Management complaints and threats
* Security control tampering attempts

**Slide 9: Access Control Principles**
* **Least Privilege:** Minimum necessary access
* **Role-Based:** Job function permissions
* **Regular Reviews:** Access right audits
* **Timely Revocation:** Immediate upon role change
* **Monitoring:** Suspicious activity detection

**Slide 10: Offboarding Security**
* Immediate access revocation
* Device return and wipe
* Credential termination
* Knowledge transfer security
* Exit interview procedures

**Slide 11: Social Engineering Defense**
* Verification of unusual requests
* No credential sharing under pressure
* Reporting of suspicious contacts
* Security procedure adherence
* Multi-factor authentication use

**Slide 12: Hands-On Activity 1 - Access Review**
* Review sample user access rights
* Identify excessive permissions
* Discuss least privilege application
* Practice access revocation procedures

**Slide 13: Hands-On Activity 2 - Physical Security**
* Identify physical security gaps
* Practice challenge procedures
* Discuss tailgating prevention
* Review visitor management

**Slide 14: Hands-On Activity 3 - Incident Response**
* Insider threat scenario simulation
* Practice reporting procedures
* Discuss containment strategies
* Review investigation cooperation

**Slide 15: Case Study - Insider Breach**
* **Scenario:** Phished finance employee → fake vendor payments
* **Impact:** ₹40 lakhs loss before detection
* **Lesson:** Multiple verification layers needed

**Slide 16: Monitoring & Reporting**
* **What to watch:** Unusual patterns, policy violations
* **How to report:** Designated channels, confidentiality
* **When to act:** Early warning signs, suspicious behaviors
* **Follow-up:** Investigation cooperation, lesson application

**Slide 17: Organizational Controls**
* Background check processes
* Security awareness training
* Access control systems
* Physical security measures
* Incident response plans

**Slide 18: Insider Risk KPIs**
* Access review completion rates
* Policy violation reports
* Security incident trends
* Training effectiveness measures
* Control implementation status

**Slide 19: Insider Risk Checklist**
- [ ] Follow least privilege principle
- [ ] Report suspicious behaviors
- [ ] Secure physical access points
- [ ] Protect authentication credentials
- [ ] Follow clean desk policies
- [ ] Verify unusual requests
- [ ] Participate in security training
- [ ] Report security concerns

**Slide 20: Security Culture Commitment**
* "Trust but verify"
* "Security is everyone's responsibility"
* "Report concerns, not confront"
* "Proactive protection beats reactive response"
* "Continuous vigilance protects everyone"
