## **PART 5: DEVICE SECURITY FUNDAMENTALS (20 Slides)**

**Slide 1: Your Device = Your Gateway**
* "If your device is compromised, your company is compromised"
* Every device is a doorway to company data
* Hackers target devices to bypass server security

**Slide 2: Common Device Security Risks**
* **Theft/Loss:** Unattended devices stolen
* **Malware:** Untrusted downloads/USBs
* **Unpatched Systems:** Old vulnerabilities exploited
* **Unsafe Wi-Fi:** Public network interception
* **Removable Media:** Infected USB drives

**Slide 3: Laptop Security Best Practices**
* **Lock Screen:** Win+L / Ctrl+Cmd+Q
* **Encryption:** BitLocker/FileVault enabled
* **Updates:** Automatic OS/antivirus
* **User Accounts:** Standard vs admin rights
* **Backups:** Regular cloud/local backups

**Slide 4: Mobile Device Security**
* **Lock Methods:** PIN, fingerprint, face recognition
* **App Sources:** Official stores only
* **Connectivity:** Disable unused Bluetooth/Wi-Fi
* **Management:** MDM compliance
* **Remote Wipe:** Find My Device/iPhone enabled

**Slide 5: USB & Removable Media Security**
* **Risks:**
  - Malware auto-execution
  - Data leakage
  - Physical loss exposure
* **Safety Rules:**
  - Company-approved drives only
  - Pre-use scanning
  - Autorun disabled
  - Encryption for sensitive data
  - Never use found drives

**Slide 6: Public Wi-Fi & Remote Work**
* **Dangers:**
  - Traffic interception
  - Fake hotspots
  - Login capture
* **Protection:**
  - VPN always enabled
  - Mobile hotspot preferred
  - File sharing disabled
  - Sensitive access avoided

**Slide 7: Physical Security at Workplace**
* Lock screens when away
* Use cable locks when traveling
* Prevent tailgating
* Secure storage for devices
* No photos of screens

**Slide 8: Lost/Stolen Device Response**
1. Report to IT/Security immediately
2. Trigger remote wipe/lock if possible
3. Change linked passwords
4. File police report
5. Never attempt solo recovery

**Slide 9: Organizational Security Controls**
* Enforced device encryption
* Automatic screen lock policies
* USB port controls
* Mobile Device Management (MDM)
* Endpoint Detection & Response (EDR)

**Slide 10: Bring Your Own Device (BYOD)**
* **Risks:** Mixed personal/work data
* **Requirements:** Security software, encryption, compliance
* **Policies:** Clear usage guidelines
* **Monitoring:** Security compliance checks

**Slide 11: Device Update Management**
* **Operating Systems:** Regular security updates
* **Applications:** Patch management
* **Antivirus:** Real-time protection enabled
* **Firmware:** Router and device updates
* **Automation:** Scheduled update checks

**Slide 12: Secure Device Disposal**
* **Data Wiping:** Multiple pass erasure
* **Physical Destruction:** Drives and devices
* **Certification:** Proper disposal documentation
* **Environmental:** Responsible e-waste handling
* **Audit:** Disposal tracking and verification

**Slide 13: Hands-On Activity 1 - Security Settings**
* Check device encryption status
* Verify screen lock settings
* Review update configurations
* Confirm backup systems

**Slide 14: Hands-On Activity 2 - USB Safety**
* Demonstrate safe USB practices
* Show encryption tools
* Practice scanning procedures
* Discuss risk scenarios

**Slide 15: Hands-On Activity 3 - Mobile Security**
* Configure mobile lock settings
* Install security apps
* Set up remote wipe
* Practice safe app installation

**Slide 16: Case Study - Device Breach**
* **Scenario:** Unencrypted laptop stolen from car
* **Impact:** Client data exposure, compliance fines
* **Lesson:** Encryption and physical security are essential

**Slide 17: Travel Security for Devices**
* **Preparation:** Backup data, enable tracking
* **Transport:** Carry-on only, discreet packaging
* **Usage:** Avoid public computers, use VPN
* **Storage:** Hotel safes, never unattended
* **Emergency:** IT contact information available

**Slide 18: Device Security KPIs**
* Encryption compliance rate
* Update compliance percentage
* Lost device incident reports
* Security policy adherence
* BYOD compliance metrics

**Slide 19: Device Security Checklist**
- [ ] Enable full-disk encryption
- [ ] Set automatic screen locks
- [ ] Keep all software updated
- [ ] Use company-approved security software
- [ ] Backup important data regularly
- [ ] Use VPN on public networks
- [ ] Report lost devices immediately
- [ ] Follow physical security protocols

**Slide 20: Device Security Commitment**
* "My device is my responsibility"
* "Encryption protects even when stolen"
* "Updates close security holes"
* "Vigilance prevents breaches"
* "Reporting saves the organization"
